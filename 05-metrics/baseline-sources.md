# Baseline Sources

**Plan, no results.** These public signals provide context only; they are not feature-usage or customer-outcome baselines.

| Public source | Available context | What it cannot establish |
|---|---|---|
| Feature-request lifecycle aggregates | Open/closed state, milestone presence, label presence, public reaction counts | Feature adoption, customer impact, cause of closure, or release completion |
| SDK npm release timestamps | Published stable versions and intervals between first stable versions | Usage, downloads, adoption, private release decisions, or release quality |
| Monthly merged-PR Search API totals | Monthly public merged-PR search totals | Team velocity, effort, quality, or customer value; bots and backports are included |
| npm download range API | Optional package-download counts if fetched manually | Unique workspaces, active users, or successful embedded usage |

Not publicly available in this project: feature usage events, workspace-level theme configuration, customer counts, conversion, retention, revenue, experiment baselines, actual sprint velocity, and support outcomes. Do not substitute public issue reactions for these measures.
