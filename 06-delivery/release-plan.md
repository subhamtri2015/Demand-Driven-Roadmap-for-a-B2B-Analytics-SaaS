# Release Plan

**Planned, not executed.**

1. Internal alpha: engineering and design review with controlled test embeds; entry/exit criteria to be agreed.
2. Flagged beta: opt-in pilot after privacy, accessibility, support, and rollback reviews.
3. GA decision: proceed only after beta evidence meets pre-agreed guardrails and documentation is ready.
4. Rollback: disable the capability flag, restore prior theme resolution behavior where feasible, communicate known impact, and retain diagnostic evidence without raw theme values.

No release has been performed. Timing must be decided by the delivery team; npm publish cadence is context, not a commitment.
