# Definition of Done

**Planned, not executed.** Proposed completion checks for future work:

- Acceptance criteria pass in supported test environments.
- Documentation and migration guidance are reviewed.
- Accessibility, security, privacy, and host-style isolation checks are completed where applicable.
- Instrumentation is validated against the tracking plan without sending raw theme values.
- Release notes, rollback path, and support handoff are prepared.
- Product, engineering, design, and documentation review is recorded.
